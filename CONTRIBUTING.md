# Contributing

Contributions that strengthen VORTEX as an audiovisual instrument are welcome.

## Useful contribution areas

- Web Audio signal routing
- microphone or MIDI input
- Three.js shaders and post-processing
- performance optimization
- accessibility and reduced-motion support
- responsive layout improvements
- export and recording features

## Development

No build step is currently required. Run a local static server from the repository root:

```bash
python3 -m http.server 8000
```

Keep changes focused and explain any changes to the audio-to-visual mapping in the pull request.
